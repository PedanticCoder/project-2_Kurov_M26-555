## Управление таблицами

Проект предоставляет легковесную СУБД, управляемую через консольный интерфейс пакета Poetry.

### Доступные команды и примеры использования

* **Показать справку:**
  ```text
  Введите команду: help
  ```
* **Создать таблицу (с автоматическим ID):**
  ```text
  Введите команду: create_table users name:str age:int is_active:bool
  Таблица 'users' успешно создана.
  ```
* **Просмотреть список существующих таблиц и их схемы:**
  ```text
  Введите команду: list_tables
  Список таблиц:
   - users (id:int, name:str, age:int, is_active:bool)
  ```
* **Удалить таблицу:**
  ```text
  Введите команду: drop_table users
  Таблица 'users' успешно удалена.
  ```
